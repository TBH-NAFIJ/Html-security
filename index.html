About & Privacy

RX CODE PROTECTOR

A browser-side toolkit for minifying and transforming HTML, CSS, and JavaScript. There is no backend, no account, and no database.

Local processing: Your code is processed inside this browser tab. It is never sent to an external API or uploaded to a server.

Local storage: Statistics, project metadata, theme, and tool options are kept in your browser's localStorage. Source code is stored only if you opt in under Settings.

CDN dependencies: Terser (minification) and javascript-obfuscator (JS obfuscation) load from jsDelivr, and icons and fonts load from Cloudflare and Google. If a library fails to load, the affected feature shows an error and your original code is kept.

Obfuscation is not encryption. Browser-delivered code can always be read, copied, and reverse-engineered. Obfuscation raises the effort required to read the code. It does not prevent theft or guarantee protection.

Testing: Always test your processed output in the target browsers. Transformations can affect behavior that depends on source layout, timing, or reflection.
